Cybersecurity · Web app · Apr – May 2026

PhishGuard

A Flask web app that scans email files, gives each one a phishing risk score, and uses a small local language model to explain the result in plain English.

Role
Developer & Tester, team of 2 with Dylan Wendling
Course
Cybersecurity class project, Washburn University
Stack
Python, Flask, HTML/CSS, JavaScript

What I built

  • A detection rule that flags emails asking for passwords, one-time codes, card or bank details, or SSNs, added to all 3 model versions of the app.
  • Drag-and-drop email upload on the main scan page and the real-time analysis page, plus a wider analysis panel for readability.
  • Test scam emails (delivery, money-request and sensitive-info scenarios) to check how detection behaves.
  • The content for the FAQ and Common Breaches education pages.

What I'd improve next

Test the rules on a labeled phishing dataset and report accuracy and false-positive rates, and match whole words so short terms like "otp" don't trigger on unrelated text.
